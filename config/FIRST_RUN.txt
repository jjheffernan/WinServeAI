WinServeAI
==========

1. Open WinServeAI from the Start menu.
2. Click Browse and choose your .gguf file.
3. Click Save, then Start.
4. When it says Ready, click Copy URL or Open chat.

The address is http://127.0.0.1:8080/v1
Leave the API key empty when you only use this PC.
You do not need to edit any files.
